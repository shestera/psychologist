# Session

## Agreed focus

## S — User report

Current experience, relevant events, meaning, goals, and the user's own words
when a short quotation materially matters.

## O — Current-interaction observations

Only observable features of this interaction. Do not infer diagnosis, motive,
appearance, or behavior that was not directly available.

## A — Working formulation

Distinguish supported facts, hypotheses, counterevidence, alternatives, and
unknowns. Note any change to the current formulation without treating it as a
diagnosis.

## P — Agreed plan

Record the user's decision, any non-medication exercise or observation, its
rationale, foreseeable burdens, opt-out conditions, and what result would be
informative.
